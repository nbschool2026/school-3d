# Школа · 3D-прогулянка

Інтерактивний перегляд зміненого світу Minecraft Java 1.16.5 у браузері.

## Як відкрити

Завантажте репозиторій і відкрийте `index.html` у браузері з підтримкою WebGL. Модель, текстури та програма вбудовані в один HTML; інтернет після завантаження не потрібен.

## Режими

- **Огляд:** обертання мишею або пальцем; масштаб — колесом або двома пальцями.
- **Прогулянка:** WASD / стрілки, миша для огляду, пробіл для стрибка, Esc для звільнення курсора.
- **Згори:** перетягування карти та масштабування.
- **Телефон:** аналоговий джойстик зліва, зона огляду справа та кнопка стрибка.
- **До входу:** повернення до початкової позиції.

Це знімок світу на момент експорту. Наступні зміни в Minecraft автоматично не синхронізуються. Редагування блоків у переглядачі не передбачене. Освітлення та деякі властивості блоків спрощені.
