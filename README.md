# Школа · 3D-прогулянка

Два режими: поточна модель Blender і попередня Minecraft-версія з користувацького збереження. Перемикач Blender / Minecraft розміщено вгорі. У кожній версії доступні огляд, вигляд згори та прогулянка.

Відкрийте index.html у сучасному Chrome, Edge, Firefox або Safari. Усі ресурси включено в HTML-файли, мережа не потрібна. Для GitHub Pages завантажте index.html і minecraft.html у корінь репозиторію. Зберігайте обидва файли поруч для роботи перемикача.

- Огляд: перетягування миші або одним пальцем; колесо, кнопки +/− або жест двома пальцями для масштабу.
- Згори: перетягування для зсуву, колесо або +/− для масштабу.
- Прогулянка: WASD або стрілки; Shift для швидшого руху. Відпускання клавіші зупиняє рух. Миша: перетягування або кнопка вільного огляду (Esc звільняє мишу).
- Мобільний: аналоговий джойстик ліворуч, перетягування іншою рукою для огляду. Підтримано одночасний рух і огляд.

Модель зовнішнього вигляду; вхід усередину корпусів обмежено.

Використано Three.js 0.180.0 (MIT). Ліцензія включена в JavaScript. Власних серверів, аналітики або зовнішніх запитів немає.
